# Seedlings Website — Phase 11 Step 2

## Account Actions + Logout

Built directly on the accepted Phase 11 Step 1 baseline.

### Changes in this step
- Adds a real Logout action to the existing latest HTML account dashboard.
- Logout uses the existing Firebase anonymous auth session and clears the existing stored customer mobile.
- After logout, the customer is returned to `/account`.
- Existing account navigation routes remain mapped to the existing Next.js routes.
- No new collections, data models, or UI redesign.

Keep `.git`, `.env.local`, `node_modules`, and `package-lock.json` from the local project when applying the package.
